# 🔄 مراسلاتي 360° — نظام التقييم المتبادل الشامل ومحرك التحليل التفاعلي
## Morasalaty & Samaa Group — 360-Degree Employee Feedback & Drag-and-Drop Analytics Engine

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FMahmoud-Hashim-pro%2Fmorasalaty-360-feedback)

نظام متكامل واحترافي مصمم لتقييم أداء موظفي شركة **مراسلاتي (Morasalaty)** ومجموعة **سماء (Samaa Group)**، يعتمد على معايير التقييم المتبادل الشامل **(360-Degree Feedback)**، مع شاشة تحليل تفاعلية ذكية قائمة على السحب والإفلات **(Drag & Drop Analytics)**.

---

## 🌟 الميزات الرئيسية للنظام

### 1. بيانات الموظفين والهيكل التنظيمي (17 موظفاً)
- يعتمد النظام على قائمة الموظفين الـ 17 المعتمدة لشركة مراسلاتي وسماء جروب عبر فرق:
  - **الإدارة (Admin)**: برئاسة محمود هاشم (مالك CRM).
  - **الدعم الفني والتقني (TS)**: برئاسة حازم خالد، ابراهيم ناصر، أحمد هاشم، احمد طارق، بهاء الدين أيمن، زياد ماضي، عبد الرحمن خالد.
  - **المبيعات (Sales)**: برئاسة احمد طه (مدير CRM) ومحمد رجب (مشرف CRM).
- ربط الموظفين بقنوات التواصل المعتمدة (انستجرام، واتساب مراسلاتي، واتساب سماء، ماسينجر، دردشة الموقع، تويتر).

### 2. ضوابط الاستبيان والسرية
- **استبعاد التقييم الذاتي تلقائياً:** كل موظف يقيّم زملاءه الـ 16 فقط، ويُمنع تقييم نفسه برمجياً.
- **الحفظ التلقائي الفوري:** تُحفظ الإجابات والملاحظات في الوقت الفعلي في `localStorage` لمنع ضياع البيانات.
- **منع التكرار في الدورة الواحدة:** عند اعتماد وإرسال التقييم، يُقفل الاستبيان مع تسجيل طابع زمني.
- **سرية التقييمات:** لا تظهر إجابات الزملاء لبعضهم البعض، وتُعرض ملخصات مجمعة في لوحة الإدارة لحماية خصوصية المقيّمين.

### 3. الموديولات العشرة (150 سؤالاً أساسياً)
1. **الالتزام والانضباط المهني** (15 سؤالاً)
2. **جودة العمل والكفاءة** (15 سؤالاً)
3. **التعاون والعمل الجماعي** (15 سؤالاً)
4. **التواصل والتعامل المهني** (15 سؤالاً)
5. **الكفاءة الفنية واستخدام الأنظمة** (15 سؤالاً)
6. **حل المشكلات والتعامل مع العملاء** (15 سؤالاً)
7. **المبادرة والتطوير المستمر** (15 سؤالاً)
8. **السلوك المهني ومستوى الثقة** (15 سؤالاً)
9. **التأثير على الفريق والإنتاجية** (15 سؤالاً)
10. **التقييم العام وفرص التحسين** (15 سؤالاً متضمنة أسئلة نوعية ومقترحات عملية)

### 4. المقياس الخماسي الموحد وخيار N/A
- درجات التقييم من 1 إلى 5:
  1. يحتاج إلى تحسين كبير
  2. يحتاج إلى تحسين
  3. يحقق المستوى المتوقع
  4. يتجاوز المستوى المتوقع
  5. أداء متميز
- **خيار مستقل:** `لا أملك معلومات كافية للتقييم (N/A)` — **يُستبعد تماماً من حساب المتوسطات** ولا يُحسب صفراً أو تقييماً سلبياً، مع توضيح عدد الإجابات الصالحة $(n)$ بجانب كل متوسط.

### 5. تقييم القيادة للمديرين (10 أسئلة قيادية إضافية)
عند تقييم من يشغل دوراً إدارياً أو قيادياً، يظهر قسم تخصصي مستقل يقيّم:
- وضوح التوجيهات
- عدالة توزيع المهام
- دعم الفريق وتطوير مساراتهم
- الاستماع وتقبل الآراء المختلفة
- حل الخلافات وتقديم الملاحظات البناءة

### 6. حلاً لإرهاق التقييم: نمطان للاستبيان (⚡ سريع vs 📝 تفصيلي)
- ⚡ **الوضع السريع الموحد (Quick Mode):** تقييم المحاور العشرة بـ 10 تقييمات إجمالية مع إبداء الملاحظات النوعية. في حال اختيار درجة منخفضة (1 أو 2)، تتوسع الأسئلة الفرعية تلقائياً لتبرير وتحديد مجالات التطوير المطلوبة بدقة.
- 📝 **الوضع التفصيلي الشامل (Detailed Mode):** الإجابة على كافة الأسئلة الـ 150 بالتفصيل.

### 7. لوحة تحكم الموارد البشرية الشاملة (HR Dashboard)
- **متابعة المؤشرات الرئيسية (KPIs):** المسجلون (17)، التقييمات المطلوبة (272)، المكتملة، ونسبة الإنجاز المؤسسية.
- **متابعة الإكمال لجميع الموظفين:** جدول تفصيلي يوضح حالة تقييم كل موظف لزملائه وحالة التقييمات الواردة إليه.
- **تقارير فردية ورسوم رادار (Radar Charts):** رسم بياني شعاعي لدرجات الموظف عبر الوحدات العشر، مع مقارنة تقييم المدير المباشر بتقييم الأقران، واستعراض الملاحظات النوعية المتكررة.
- **تقارير الفرق:** مقارنة أداء فرق العمل (Admin / TS / Sales) ومعدلات إنجازها.
- **تحليل المديرين:** قياس الكفاءة القيادية للمديرين المباشرين مقارنةً بالأقران.
- **توصيات التطوير المؤسسي:** برامج الإرشاد ومصفوفة تحسين الأداء.

### 8. شاشة التحليل التفاعلية القائمة على السحب والإفلات (Drag & Drop)
- متوفرة كشاشة مدمجة داخل لوحة الـ HR (`🎯 مختبر التحليل`)، وكذلك كنافذة مستقلة كاملة (`analysis.html`).
- **مكتبة المقاييس:** أبعاد الموظفين، فرق العمل، مقاييس الأداء، وحدات التقييم، فلاتر الأداء.
- **4 مناطق إفلات تفاعلية:**
  - 📐 المحور الرئيسي (الأبعاد: Dimensions)
  - 📏 القيم والمقاييس (Values / Measures)
  - 🗂️ التجميع والتصنيف (Group By)
  - 🔽 الفلاتر والتصفية (Filters)
- **أنماط عرض الرسوم:** أعمدة (Bar)، خطي (Line)، رادار (Radar)، خريطة حرارية (Heatmap)، وجدول محوري (Pivot Table).
- **قوالب تحليلية سريعة بنقرة واحدة:** مقارنة الفرق، أعلى الوحدات أداءً، تقييم المديرين، وفرص التطوير الملحّة.
- **التحليل التلقائي وتوليد الرؤى:** استخراج آلي لأبرز الفروقات والانحرافات.

## 💻 التشغيل المحلي السريع (Local Development)

النظام مبني بتقنيات الويب القياسية بدون أي متطلبات تثبيت خارجية معقدة:

```bash
# تشغيل خادم محلي عبر بايثون:
python -m http.server 8080

# أو تشغيله عبر Node:
npx serve -l 8080
```

افتح المتصفح على:
- **بوابة التقييم ولوحة HR:** `http://localhost:8080/index.html`
- **محرك التحليل الاستكشافي المستقل:** `http://localhost:8080/analysis.html`
